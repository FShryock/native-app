# 🏐 Volley-Connect

Volley-Connect is a **React Native mobile app** with a **Django backend** that lets volleyball players log their games, track where they play, manage their player profile, and find Local tournaments (indoor, sand, grass).  

It’s a personal side project designed to showcase cross-platform mobile development, authentication, and backend integration.

---

## 🚀 Features

- 👤 **User Authentication** – Secure login and registration powered by Django REST API  
- 🗺️ **Interactive Map** – View and log locations where you’ve played using `react-native-maps`  
- 🏆 **Game Tracking** – Record match results, dates, and court locations  
- 🖼️ **Profile Management** – Manage your name, email, and profile picture  
- 💾 **Persistent Data** – All user and game data stored in a Django database  

---

## 🧱 Tech Stack

| Category | Tools |
|-----------|--------|
| Frontend | [React Native](https://reactnative.dev/) with [Expo](https://expo.dev/) |
| Backend | [Django](https://www.djangoproject.com/) + [Django REST Framework](https://www.django-rest-framework.org/) |
| Maps | [react-native-maps](https://github.com/react-native-maps/react-native-maps) |
| Auth | Custom Django token-based authentication |
| Storage | Django PostgreSQL / SQLite (configurable) |
| UI | React Native Paper / Vector Icons |
